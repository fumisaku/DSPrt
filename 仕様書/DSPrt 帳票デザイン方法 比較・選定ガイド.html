1. 帳票デザインの基本的な考え方

帳票システムは 「デザイン時（レイアウト作成）」 と 「実行時（データ流し込み→印刷）」 の2段階に分かれます。

デザイン時
FastReport Designer（スタンドアロン）
で .frx を作成
→
実行時
DSPrt が JSON データを .frx に流し込み
ImageExport → PrintDocument → 自動印刷
帳票追加は ./Reports/ に .frx を置いて DSPrt.json に登録するだけ。

5. 印刷フロー（実装確定版）

FastReport OS 版固有の制限への対処として確立したフロー：
report.Prepare() → ImageExport(PNG, 203dpi, SaveStreams=true) → Bitmap リスト → PrintDocument.PrintPage で描画 → doc.Print()
ステップクラス / メソッド備考
① .frx 読み込みreport.Load(frxPath)相対パスを絶対パスに解決
② データバインドreport.RegisterData(DataTable, name)JSON → DataTable 変換（Newtonsoft.Json）
③ レンダリングreport.Prepare()レイアウトとデータを結合
④ ページ画像生成ImageExport(Png, 203dpi, SaveStreams=true)全ページ分の Stream を生成
⑤ Bitmap 変換new Bitmap(stream)System.Drawing.Common 8.0.8 が必要
⑥ 印刷送信PrintDocument → e.Graphics.DrawImage()プリンター名・部数・両面・用紙サイズを設定
⑦ 完了通知PR_DONE 電文送信status: "done" | "error"

実行時コード（確定版）

// NuGet: FastReport.OpenSource 2025.1.0 + System.Drawing.Common 8.0.8
using FastReport;
using FastReport.Export.Image;
using FastReport.Export.Html;
using System.Drawing.Printing;

FastReport.Utils.Config.WebMode = true;  // ライセンスダイアログ非表示
var report = new Report();
report.Load("./Reports/FinalResult_A4.frx");

// JSON -> DataTable -> バインド
report.RegisterData(jsonArrayToDataTable(json, "Results"), "Results");
report.Prepare();

// 印刷（Report.Print() は OS 版に存在しない → ImageExport で代替）
var export = new ImageExport {
    ImageFormat = ImageExportFormat.Png,
    Resolution  = 203,
    SaveStreams  = true,
    SeparateFiles = true
};
report.Export(export, string.Empty);
var pages = export.GeneratedStreams
    .Select(s => { s.Position = 0; return new Bitmap(s); }).ToList();

var doc = new PrintDocument();
doc.PrinterSettings.PrinterName = "Canon TR8600";
doc.PrinterSettings.Copies = 2;
int idx = 0;
doc.PrintPage += (_, e) => {
    e.Graphics!.DrawImage(pages[idx++], e.MarginBounds);
    e.HasMorePages = idx < pages.Count;
};
doc.Print();

// プレビュー（PDF 非対応 → HTML で代替）
var html = new HTMLExport { EmbedPictures = true, SinglePage = true };
report.Export(html, "./Spool/Preview/job001.html");

① ジョブログ DataGrid（受信時刻 / jobId / layoutId / 部数 / 状態 / 完了時刻 / エラー）。200件保持。複数選択→再印刷ボタン（完了・エラーのみ有効）。再印刷 jobId サフィックス: _R
