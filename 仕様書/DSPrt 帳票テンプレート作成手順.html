DSPrt 帳票テンプレート作成手順

FastReport Community デザイナー | .frx ファイル | DSPrt への登録まで

Step 1 ： FastReport Community デザイナーのインストール

GitHub から無料で入手できます（MIT ライセンス）
最新版: v2026.2.0 — FastReport.Community.2026.2.0.zip にデザイナー exe が含まれています。
1
以下の URL にアクセスしてダウンロードします。
https://github.com/FastReports/FastReport/releases/latest
FastReport.Community.2026.2.0.zip をクリック
2
ZIP を展開します。例: C:\Tools\FastReportCommunity\
3
展開したフォルダ内の デザイナー exe（FastReport.Designer.exe 等）を確認します。
ショートカットをデスクトップに作成しておくと便利です。
4
.frx ファイルの関連付けを設定します（任意）。
エクスプローラーで .frx ファイルを右クリック →「プログラムから開く」→ デザイナー exe を選択
→ DSPrt の「デザイナーで開く」ボタンが使えるようになります。
注意: デザイナーのバージョン（2026.2.0）と DSPrt が使用する NuGet（2025.1.0）は異なります。
.frx の XML フォーマットは後方互換性があるため、2026.2.0 デザイナーで作成した .frx は 2025.1.0 ランタイムで読み込めます。
問題が発生した場合は DSPrt の NuGet も 2026.2.0 に更新してください（後述）。

Step 3 ： データソースの定義

デザイナーでデータソースを登録することで、フィールドをドラッグ＆ドロップできるようになります。

1
メニュー データ(D) → データソースを追加 を選択
2
Business Object / JSON ソース または DataBase を選択
DSPrt では「XML / JSON ファイル」か「Business Objects（DataTable）」を選ぶ
3
./Reports/TestData/ にあるサンプル JSON を読み込む
例: PR_PRINT_FinalResult_テスト.json の "Results" 配列を登録
4
カラム名（フィールド名）が左側のデータソースパネルに表示されたら完了
フィールドの記述方法：
テキストオブジェクトに [テーブル名.列名] 形式で記述します。
例: [Results.PlayerName]、[Results.Rank]、[DA_Master.DA_CompName]

Step 5 ： テンプレート作成の実践例

例A ： 決勝入賞者名簿（FINAL_RESULT_A4）

📋 作成手順
1
デザイナーで新規レポートを作成（A4縦、余白10mm）
2
データソースに PR_PRINT_FinalResult_テスト.json の Results 配列を登録
3
ReportTitle バンド:
テキスト「決勝入賞者名簿」（16pt 太字 中央）
テキスト「[CmpName]　[KbnName]」（9pt 中央）
4
PageHeader バンド:
列ヘッダー行（順位・背番号・氏名・所属・得点）を TextObject で配置
5
DataBand に Results を設定し、フィールドをドラッグ配置:
[Results.Rank] / [Results.PlayerNo] / [Results.PlayerName] / [Results.ClubName] / [Results.Score]
6
PageFooter: [PageN] / [TotalPages] を右端に配置
7
./Reports/FinalResult_A4.frx に保存（既存を上書き）

例B ： 表彰状（AWARD_CERTIFICATE）

🏆 作成手順
1
A4縦、余白15mm で新規作成
2
DataBand の DataSource を Awards に設定
（1件1ページにするため DataBand の「StartNewPage」プロパティを ON）
3
固定テキスト「表　彰　状」を大きく配置（24pt 以上、縦中央）
4
差し込みフィールドを配置:
[Awards.PlayerName]（受賞者名 / 18pt）
[Awards.KbnName] [Awards.RankName]（区分・順位）
[Awards.CmpName]（競技会名）
5
./Reports/Award_Certificate.frx に保存

Step 6 ： DSPrt.json への登録

作成した .frx は DSPrt.json（または DSPrt_General.json / DSPrt_Award.json）の Layouts に登録します。

{
  "Layouts": [
    {
      "LayoutId":    "FINAL_RESULT_A4",
      "FrxPath":     "./Reports/FinalResult_A4.frx",
      "DataType":    "DV_Result",
      "PrinterName": "Canon TR8600",
      "Copies":       2,
      "Duplex":       "OneSided",
      "PaperSize":    "A4"
    },
    {
      "LayoutId":    "AWARD_CERTIFICATE",
      "FrxPath":     "./Reports/Award_Certificate.frx",
      "DataType":    "DV_Result",
      "PrinterName": "Canon TR8600 Award",
      "Copies":       1,
      "Duplex":       "OneSided",
      "PaperSize":    "A4"
    }
  ]
}
フィールド設定値の例説明
LayoutIdFINAL_RESULT_A4サーバーから指定するキー。大文字推奨
FrxPath./Reports/FinalResult_A4.frx実行ファイルからの相対パス
DataTypeDV_Result / DA_Master / DS_Status帳票が使うデータ種別
PrinterNameWindowsのプリンター名と完全一致空欄の場合はデフォルトプリンター
Copies1 〜電文の copies で上書き可能
DuplexOneSided / TwoSidedLongEdge両面印刷設定
PaperSizeA4 / A3 / B5Windowsの用紙名と一致させる

Step 7 ： DSPrt でのプレビュー確認

1
DSPrt を起動して「接続」（またはオフラインのままでも可）
2
「帳票設定」タブで作成した layoutId が一覧に表示されているか確認
3
手動プレビュー確認（開発時）: TestData の JSON を使ってデバッグ用に簡易テストコードを追加するか、 サーバーから PR_PRINT を実際に送信して「プレビュー」タブで HTML 表示を確認

参考 ： よく使う .frx XML 記法

用途.frx XML 記法
フィールド表示Text="[Results.PlayerName]"
ページ番号Text="[PageN] / [TotalPages]"
今日の日付Text="[Date]"
罫線（全辺）Border.Lines="All"
背景色FillColor="LightGray"
フォントFont="MS Gothic, 10pt, style=Bold"
横位置揃えHorzAlign="Center" / Left / Right"
縦位置揃えVertAlign="Center"
DataBand のデータソース指定<DataBand DataSource="Results" ...>
1行1ページDataBand に StartNewPage="true"
サイズ単位mm × 3.78 = 内部単位（例 A4幅 210mm → PaperWidth="210"）
フォントの注意: MS Gothic / MS Mincho 等の日本語フォントは Windows に標準搭載されています。 実際の印刷結果と一致させるため、デザイナーで確認してから保存してください。
